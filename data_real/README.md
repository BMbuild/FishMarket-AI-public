# data_real
* `cpi_u_annual.csv`: US CPI-U, all items, annual average, 1982-84=100, not seasonally adjusted. 1950-2020 from the BLS historical CPI-U table
  (https://www.bls.gov/cpi/tables/supplemental-files/historical-cpi-u-202101.pdf); 2021-2024 from a state-government copy of the BLS annual averages
  (https://sfa.senate.michigan.gov/Economics/Uscpi.pdf). Replace with the official BLS series when convenient and update 2025 when published.
* Files written by `scripts/fetch_*.py` land here too.
